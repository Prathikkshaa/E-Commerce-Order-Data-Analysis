# E-Commerce Order Data Analysis

## About the Project

This repository contains an e-commerce order dataset with details about customer orders, platform used, product categories, delivery performance, and customer feedback. The data is structured to provide insights into service quality, order delays, and customer satisfaction. It's designed for performing data analysis, creating visualizations, and building predictive models for e-commerce platforms.

## Dataset Overview

The dataset includes order details for multiple e-commerce platforms and contains the following columns:

- **Order ID**: Unique identifier for each order
- **Customer ID**: Unique identifier for each customer
- **Platform**: The platform from which the order was made (e.g., JioMart, Blinkit, Swiggy Instamart)
- **Order Date & Time**: The date and time when the order was placed
- **Delivery Time (Minutes)**: Time taken for the order to be delivered in minutes
- **Product Category**: Category of products ordered (e.g., Fruits & Vegetables, Dairy, Beverages, etc.)
- **Order Value (INR)**: Total value of the order in Indian Rupees (INR)
- **Customer Feedback**: Feedback provided by the customer about the order experience
- **Service Rating**: Rating given by the customer on the service (1 to 5 scale)
- **Delivery Delay**: Whether there was a delay in the delivery (Yes/No)
- **Refund Requested**: Whether the customer requested a refund (Yes/No)

## Features of the Analysis

The dataset enables analysis in the following areas:
- **Customer Satisfaction**: Exploring the relationship between customer feedback, service ratings, and refund requests.
- **Delivery Performance**: Analyzing delivery times and delays across different platforms and product categories.
- **Order Trends**: Identifying the most popular product categories and platforms used by customers.
- **Refund and Service Issues**: Analyzing patterns in refund requests and service issues to improve customer satisfaction and operational efficiency.
